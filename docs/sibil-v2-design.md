# Sibil V2

Baseline backup: branch backup/pre-v2, commit 78e6ce8047a1658fd47d4ad2fe211d1c6310f7c7. This preserves repository code/assets, not remote spreadsheet contents or Script Properties.

Direction: a payment clerk's workspace for a local internet provider. Customer names, selected month, and payment state are the core content. A single restrained green collection-progress strip gives the page identity; avoid decorative gradients, glass, glow, uppercase headings and repeated cards. Use white/light-grey surfaces so the original navy/green SulNet logo is legible.

Palette: surface/canvas #FFFFFF, ink/navy #173865, action green #397523, brand green #70B332, cyan #007C9E. Semantic pending red #A33226 and transfer blue #245B89. Verify text contrast rather than using logo green for small text.

Type: Source Sans 3 with system sans fallback, 16px body, 28px page title, 14px secondary text, tabular figures for metrics. Left-aligned labels and names; numeric totals aligned consistently.

Desktop: brand/account header; title and month toolbar; one summary band; customer search/filter/table beside payment editor; annual trend below. Mobile: payment editor is a modal dialog from a customer row; no sideways page scroll. Footer explicitly identifies Sibil V2.

Review against brief: no SaaS marketing hero, arbitrary badges, decorative numbering, monospace captions, animated entrances, or generic dark/neon palette. No invoice amounts or new spreadsheet model. Selected customer uses existing row+name check. No actual Google writes during local tests.
